# Text statistics teaching plan

## Lesson: Text statistics

**Learning goal:** Use string methods, regular expressions, arrays, and maps to summarize text.

**Key talking points:**
1. Validate inputs before using string methods.
2. Lowercase text and use a Unicode regular expression to separate words from punctuation.
3. Use a `Map` to count repeated words and sort the results.

**Exercise:** Add a `longestWord(text)` function and test it with punctuation, ties, and empty input.
